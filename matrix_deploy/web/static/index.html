      Fiber Test

      not tested yet

      Checks both ends of every fiber link: the light each switch SFP and each encoder/decoder SFP receives and sends, the loss in each direction, SFP health, and the error counters on both ends. Test again after cleaning or replugging a fiber to see the light change and whether errors are still going up. Read-only - nothing on the switches or rooms is changed and the counters aren't cleared. Uses the router and switch passwords saved for the lab, and the SSH and sudo passwords from the sidebar for each room's NMS.

      Switches

      Each switch's ports coloured by the test result; problems and warnings are listed under each switch. Click a port for both ends of its link (switch and device light, loss each way, errors), or open Modules for the full list. By room lists every encoder/decoder fiber port with its switch port, the light at both ends and the loss.

      fiber OK warning problem copper / DAC unused SFP no module A light bar under the number = link up.

      Device Health Check

      not checked yet

      Finds the hardware problems behind failed updates, network drops and corrupt downloads, and tells you what to do about them. Nothing on the device is changed.

      1. What are you checking?
      2. Pick the room
      2. Enter the device's address and login
      More options (SSH port, separate sudo password)

      Used for this check only, never saved. A Matrix room behind a lab router is reached at the router's IP with SSH port 200 + room number (OR 3 = 203) and the room login (user arthrex, not the router's admin). For rooms in a lab you've set up, A room in this lab does this for you.

      2. Follow these steps
      1. Download the check script to this computer. Download MatrixHealthCheck.ps1
      2. In BeyondTrust, open File Transfer and upload it to the device's C:\Users\Public\Documents folder.
      3. In BeyondTrust, open Shell, paste this command and press Enter:
        powershell -NoProfile -ExecutionPolicy Bypass -File C:\Users\Public\Documents\MatrixHealthCheck.ps1
      4. Wait about 30 seconds. The result and what to do are printed right there in the shell.
      5. To keep a record: download the .json file it saved (same folder) with File Transfer, then open it here.

      Sitting at the device instead? Open PowerShell as Administrator, run the same command and add -Open to see the report in a browser.
