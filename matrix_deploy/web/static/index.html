Configure, Reset & Diagnostics

Configure sets the web-app folders/pairing key and trusts all room API origins. Reset undoes a previous web app deploy (removes staged/deployed files, restores the original systemd entrypoint). Diagnose dumps web asset listings, config values, service status, and AppArmor denials - useful for chasing 403s on static JS assets.

Matrix App Remote

Inspect and screenshot a room's Matrix App (Electron kiosk) over an SSH tunnel. Uses the SSH password from the sidebar. The room picker follows the room you tick in the sidebar. For the NMS Demonstrator or the web app, use the NMS / App buttons on the room's row in the sidebar.

Matrix App (Electron kiosk)
Enable relaunches the kiosk app with DevTools (needs sudo). Then View opens the inspector in a Chromium browser, and Screenshot saves a PNG of the app. Disable removes the flags and relaunches the kiosk normally.
